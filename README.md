Thread the neon arena, collect embers, and survive the rising enemy waves.

Play: Move with WASD or arrow keys, aim with the mouse, and hold Shift, Space, or right-click to dash. Your ship fires automatically.

Run: node main.ts packages the game; node serve.ts serves it at http://localhost:8080.
